# Lavlu Academy Digital Notes Store

Responsive Bengali storefront prototype for selling educational PDF notes.

## Current prototype features
- Responsive homepage and product cards
- Search and category filters
- Product detail modal
- Demo cart
- Bengali typography and mobile layout

## Important
This is a front-end prototype only. It does **not** yet have user accounts, a database, real orders, payment processing, protected PDF storage, online reading, or downloads. Do not accept payments or upload paid PDFs until those backend features are implemented and tested.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.
